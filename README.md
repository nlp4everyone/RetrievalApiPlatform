# 🤖 AssistantApiPlatform

An OpenAI Assistants API–compatible backend — assistants, threads, messages and runs — built with FastAPI and backed by PostgreSQL, Redis + TaskIQ for background generation, and MLflow + MinIO for tracing/artifacts. Bring your own OpenAI-compatible LLM server (vLLM, SGLang, ...).
